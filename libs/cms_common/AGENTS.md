# cms_common - Common libraries for CMS

This library contains the shared models, services, helpers that are used across CMS solution

## Location of files

| Type     | Directory | File name             | Class name                         |
| ---------| --------- | --------------------- | ---------------------------------- |
| Model    | models    | (no additional rules) | same with filename, but PascalCase |
| Service  | services  | ends with `_service`  | ends with `Service`                |
| Helper   | helpers   | ends with `_helpers`  | ends with `Helper`                 |
